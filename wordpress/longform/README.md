# Расширение прежних материалов

Цель — 100 существующих черновиков и десять опубликованных статей. `manifest.json` содержит только текущий проверенный пакет; его размер не означает завершение всех 110 материалов. `quality.json` фиксирует исходный объём и SHA256 полного редакционного текста.

Для прежних черновиков сохраняется полный исходный префикс, в канонический файл здесь записывается только дополнение. Для опубликованных статей дополнение само содержит ≥10 000 видимых знаков. `refine-longform.php` проверяет все принадлежащие импортёру записи до первой записи, дописывает нативные блоки и сохраняет исходные блоки, заголовки, статусы, обложки и расписание. Ручные изменения исходного текста блокируют автоматическое дополнение.

Повторный запуск сохраняет уже применённую редакцию. Другая редакция требует отдельной подготовки, чтобы не перезаписать ручную работу. Схема процесса и таблица доступны в SVG/CSV; ссылки ведут к ассетам темы.

Полная компиляция: `python3 wordpress/tools/compile-longform.py <каталоги авторов>`. Для готового подмножества — `--ready-only`; для проверки без записи — `--audit-only`. Частичный импорт требует `SY3_LONGFORM_PARTIAL_IMPORT=1`, предварительная проверка — `SY3_IMPORT_DRY_RUN=1`. Production дополнительно требует `SY3_ALLOW_PRODUCTION_IMPORT=1` и отдельной authority владельца, предоставленной в текущей задаче.

`audit-longform.php` считает основной текст без схем, источников и контактных панелей. Режим `SY3_LONGFORM_REQUIRE_ALL=1` завершается успешно только при наличии всех 311 материалов с таблицами, схемами, обложками и подтверждением точной версии текста. Итог увеличен с 211 после отдельного поручения владельца о ста дополнительных статьях Beget; для промежуточного плана число можно явно передать через `SY3_LONGFORM_EXPECTED_TOTAL`.
