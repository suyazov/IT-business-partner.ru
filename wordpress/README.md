# WordPress: Сутри и личный сайт Артёма

Текущий этап: проверяемая версия в изолированных локальных WordPress. Production ещё не менялся.

- `theme/` — собственная адаптивная тема, обычный редактор блоков, редактируемые меню.
- `plugin/` — типы «Услуги», «Кейсы», архив проектов, связи материалов, SEO, sitemap-совместимые адреса, `llms.txt`, sales feed и точные редиректы.
- `content/` — 3 услуги, 2 подробных кейса, 8 новых статей, страницы и сохранённые публичные материалы прежнего сайта.
- `tools/import-content.php` — импорт через WP-CLI; повторный запуск не перезаписывает вручную изменённый контент.
- `docs/ROLLOUT.md` — границы публикации, перенос адресов, восстановление и проверки.
- `docs/DESIGN.md` — выбранное владельцем направление, самостоятельная графика и режимы анимации.

## Установка в согласованное тестовое окружение

Нужен установленный WordPress с PHP 8.1+, WP-CLI и отдельной базой. На production планируется MariaDB; SQLite используется только для изолированной проверки, без подключения к общему серверу баз.

1. Разместить `theme/` как `wp-content/themes/sy3` и `plugin/` как `wp-content/plugins/sy3-content`.
2. Активировать тему `sy3` и плагин `sy3-content`.
3. Проверить состав импорта:

```bash
SY3_IMPORT_DRY_RUN=1 wp eval-file /exact/source/wordpress/tools/import-content.php --path=/exact/wordpress
```

4. На новой тестовой установке импортировать основной сайт:

```bash
wp eval-file /exact/source/wordpress/tools/import-content.php --path=/exact/wordpress
```

Для отдельной установки личного сайта:

```bash
SY3_SITE_MODE=personal SY3_MAIN_URL=https://sy3.ru wp eval-file /exact/source/wordpress/tools/import-content.php --path=/exact/personal-wordpress
```

Импорт сначала устанавливает режим сайта. Менять роль существующей установки этим скриптом нельзя. Несвязанные записи с теми же адресами вызывают остановку. Заводские страницы WordPress удаляются только на доказанно новой тестовой установке, по их точным ID; скрипт их не удаляет.

Обычный повторный импорт сохраняет тексты. `SY3_IMPORT_UPDATE=1` обновляет только записи импорта, чьи тексты всё ещё совпадают с сохранённым хешем. Изменённые вручную записи сохраняются, импорт останавливается с указанием конфликта. Автоматическое восстановление ручных изменений не выполняется.

Запуск на production дополнительно блокируется без `SY3_ALLOW_PRODUCTION_IMPORT=1`. Эта переменная — технический предохранитель, а не разрешение владельца на публикацию.

## Работа редактора

- Главная и обычные страницы: «Страницы», редактор блоков.
- Услуги и кейсы: отдельные разделы панели управления; карточки разделов формируются автоматически из опубликованных записей.
- Статьи: «Записи», рубрики CRM / Интеграции / ИИ / Процессы.
- Меню: «Внешний вид → Меню».
- На главной динамические подборки вставлены блоками shortcode. Редактор меняет тексты страниц и записей; новые опубликованные записи попадают в подборки.
- Публичные обращения идут через Telegram, email и телефон. Формы с неподтверждённой доставкой и аналитические трекеры не добавлены.

## Проверки

```bash
python3 wordpress/tools/smoke.py http://127.0.0.1:8186 http://127.0.0.1:8187
git diff --check
```

HTTP smoke новой версии прошёл для 41 HTML-страницы, 14 локальных ассетов, 8 точных редиректов, sitemap и вложенных sitemap, llms.txt и обоих sales feeds. Отдельно проверены мобильные меню обоих сайтов, отсутствие переполнения на 390px и загрузка главной в настоящем редакторе WordPress: 112 корректных блоков. Движение, пауза, `prefers-reduced-motion`, SVG fallback и потеря WebGL-контекста проверены в отдельном Chromium со SwiftShader; это эмуляция мобильного viewport, не тест реального телефона. После ошибочной очистки общих cookies первая проверка закрыта; дальнейшие браузерные действия выполняются только в собственном изолированном контексте и своей вкладке.

Версии локального стенда: WordPress 7.1.3, PHP 8.4.27. Наличие перевода панели `ru_RU` на этом стенде не подтверждено; пользовательские тексты русские. На целевом сервере проверяется доступная поддерживаемая версия WordPress, расширения PHP и локализация до переключения домена.
