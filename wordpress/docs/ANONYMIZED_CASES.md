# Обезличенные кейсы и выравнивание каталога

Theme 1.4.7 задаёт одинаковые рамки 4:3 всем обложкам основного каталога кейсов. `object-fit:contain` сохраняет содержимое скриншотов целиком. Высота обложек и начало текста в каждом ряду совпадают; на мобильном сохраняется одна колонка. Личная версия и редакционная сетка главной не переоформляются.

Два новых кейса добавлены в начало cases.json:

- `hiring-funnel-dashboard`: разработанный дашборд найма в формате воронки. Завершение подтверждено прямым текущим сообщением владельца. Исходник интерфейса пока не найден; у владельца запрошена ссылка. Публичный текст ограничен этим фактом и общими принципами чтения воронки. Фильтры, источники данных, реальные этапы, метрики, сроки и бизнес-эффект не приписываются проекту. Обложка и иллюстрация обозначены как редакционная схема. Кейс включён в шесть избранных работ на главной.
- `crm-hr-requirements`: подготовленный аналитический пакет для связи анкеты CRM с внутренним кадровым процессом. Проверены исходный README и документ требований: источники истины, сопоставление, статусы, права, ошибки и границы работ. Результат — ТЗ, готовое к декомпозиции и оценке; внедрение не заявляется.

Приватная карта доказательств хранится вне Git: private/hiring-case-facts.json, SHA256 `79ba1e0e5d673f3647cad225a6c0b4b4a19662306a077377b88c77c844f03362`. Частные названия, репозитории, номера задач, ссылки и персональные данные в source и public payload не переносятся. Все 25 прежних записей cases.json сохранены без изменения.

`tools/add-anonymized-cases.php` — отдельный insert-only импорт двух точных slug, без полного переимпорта сайта. Он проверяет production/preview identity, HTTPS/authority, владельца, существующие услуги/темы и все идентичности до записи. Существующие записи не редактирует; неизвестное состояние останавливает работу. Для новых кейсов создаёт body/owned metadata/relations, назначает существующие темы, публикует и проверяет read-back в транзакции. Старые posts/meta/relationships и редакционные часы должны совпасть до/после. Повторный запуск ничего не пишет. Новые записи стоят в начале каталога; остальные записи и личный сайт сохраняются.

```sh
HTTPS=on SERVER_PORT=443 SY3_ALLOW_PRODUCTION_IMPORT=1 SY3_IMPORT_DRY_RUN=1 wp --path=/var/www/sy3-wordpress --allow-root eval-file wordpress/tools/add-anonymized-cases.php
```

Preview: четыре ширины каталога 320/390/768/1440, одинаковые covers/copy tops по рядам, обе страницы на 320, корректные SVG, caption/CTA/related services, нативные блоки 24/34 без freeform, create+idempotence и production dry-run. Главная, sitemap, llms.txt, sales feed включают кейсы. JS ошибок, overflow и сломанных изображений нет. Доставка после independent exact-head review; evidence в PR и private/hiring-cases-*.json. Новых backups нет.
