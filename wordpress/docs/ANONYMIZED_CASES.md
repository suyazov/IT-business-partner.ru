# Обезличенные кейсы и выравнивание каталога

Theme 1.4.7 задаёт одинаковые рамки 4:3 всем обложкам основного каталога кейсов. `object-fit:contain` сохраняет содержимое скриншотов целиком. Высота обложек и начало текста в каждом ряду совпадают; на мобильном сохраняется одна колонка. Личная версия и редакционная сетка главной не переоформляются.

Два новых кейса добавлены в начало cases.json:

- `hiring-funnel-dashboard`: после получения ссылки владельца найдены и прочитаны исходники вкладки, расчётов, доступа, инструкция и сохранённая сверка CRM. Кейс описывает два режима, переход от этапа к откликам и резюме, хронологию конверсии и серверные проверки прав. Три изображения сняты с исходного интерфейса с полностью демонстрационными данными; подписи явно отделяют их от показателей клиента. Историческая абстрактная SVG больше не используется в этом кейсе. Подробности — [HIRING_DASHBOARD_CASE.md](HIRING_DASHBOARD_CASE.md). Кейс остаётся в избранных работах главной.
- `crm-hr-requirements`: подготовленный аналитический пакет для связи анкеты CRM с внутренним кадровым процессом. Проверены исходный README и документ требований: источники истины, сопоставление, статусы, права, ошибки и границы работ. Результат — ТЗ, готовое к декомпозиции и оценке; внедрение не заявляется.

Приватная карта доказательств хранится вне Git: private/hiring-case-facts.json, SHA256 `79ba1e0e5d673f3647cad225a6c0b4b4a19662306a077377b88c77c844f03362`. Частные названия, репозитории, номера задач, ссылки и персональные данные в source и public payload не переносятся. Все 25 прежних записей cases.json сохранены без изменения.

`tools/add-anonymized-cases.php` — исторический insert-only импорт исходных двух кейсов. Он не предназначен для новой редакции с обложкой и повторно для неё не запускается. Обновление существующего кейса выполняется отдельным scoped CAS для ID574 с точной проверкой body/полей/meta, одной native media attachment и сохранением остальных записей/редакционных часов. Общий import-content.php для этой правки не запускается.

```sh
HTTPS=on SERVER_PORT=443 SY3_ALLOW_PRODUCTION_IMPORT=1 SY3_IMPORT_DRY_RUN=1 wp --path=/var/www/sy3-wordpress --allow-root eval-file wordpress/tools/add-anonymized-cases.php
```
