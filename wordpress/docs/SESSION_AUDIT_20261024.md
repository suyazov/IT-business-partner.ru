## Остаётся завершить

1. **Метрика, Яндекс Вебмастер и Google Search Console.** Плагин есть, но production-настройки пусты. Нет подтверждённого счётчика, проверки прав, добавления sitemap в кабинетах и поступления статистики. Наличие логина или пароля само по себе не означает подключение.
2. **Автоматический выпуск статей.** `sy3_editorial_paused=true`; editorial timer не активен. Перенос намеренно сохранил прежние approval hashes. Перед запуском нужны предметная приёмка обновлённых текстов и актуальное подтверждение редактора; отключать проверку hashes нельзя. Запрошенный ритм: экспертная серия раз в три дня, поисковые/Beget — ежедневно после проверки.
3. **Форма с honeypot и доставкой в оба канала.** Код и preview подготовлены в PR22, но production-плагин формы не активен и `sy3-leads.timer` не запущен. Работа public inbox ботов не доказывает работу веб-формы. Нужны узкий rollout формы/privacy/dispatcher и разрешённая проверка доставки.
4. **Полный естественный диалог через бота.** Нет подтверждённого прохождения посетитель → обычный Reply владельца → preview → кнопка → ответ исходному посетителю после последних исправлений. Отдельно требуется проверить MAX-карточку в клиенте на реальном обращении. Offline tests и API edit уведомления не заменяют эти проверки.
5. **Все изображения портфолио.** Массового переноса 3–4 изображений на каждый кейс нет. В 27 опубликованных кейсах только кейс найма содержит как минимум два дополнительных body image. Дополнительные снимки остальных проектов ещё нужно сопоставить с источниками и встроить в текст/галереи.

Техническая проверка дизайна не доказывает рост обращений. Читательская проверка предложения и измерение конверсии ещё не проводились. Второй сайт в этой сверке не переделывался.
