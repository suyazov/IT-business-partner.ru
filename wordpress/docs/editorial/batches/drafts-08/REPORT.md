## Источники и границы

[SOURCE_CHECKS.md](SOURCE_CHECKS.md) фиксирует точные разделы и пределы выводов. Устаревший путь миграции Beget недоступен, оригинальный href сохранён, проверена актуальная официальная инструкция. RFC Editor RFC 8259 вернул 429; проверен официальный IETF mirror. Эти исключения явно помечены в manifest вместо ложного статуса прочитанной исходной страницы.

Gateway поддерживает вызовы инструментов, но не заменяет авторизацию приложения. Каталог/поддомен не объявлены изоляцией. DNS reset не предлагается при внешней почте. Session-lock зависит от handler; read_and_close не совместим с последующей необходимой записью без отдельного проектирования. Снапшот не объявлен гарантированно согласованной БД. ЮKassa HTTP 200 не превращён в универсальный контракт других отправителей. Правила вместимости, финансов и полномочий задаёт организация, а не редактор.

Real Flacon ограничен подтверждёнными работами публичного портфолио. Не приписаны клиенту новые тесты оплат, возвратов и отказов. Независимая проверка — методика, без заявления, что каждый старый проект проходил отдельного ревьюера. Никаких вымышленных внедрений CRM детцентра/платформы экспорта/финансовой системы.

READER_TEST_NOT_RUN. Читательскую/браузерную проверку и независимое review точных hashes выполняет координатор. Следующий шаг — editorial review и display QA, затем отдельная разрешённая доставка. `edits.json` хранит индивидуальные решения, `build.py` воспроизводит их, `check.py` и `QA.json` фиксируют offline-проверку. Временные копии не создавались.
