## Факты и ограничения

[Первичные источники](SOURCE_CHECKS.md) проверены по относящимся разделам. CWV-пороги/75p сверены по web.dev; lazy главного изображения не универсальная оптимизация; no-cache отличается от no-store; WP object cache непостоянен по умолчанию; пагинация не объединена canonical с первой частью. IIBA/W3C/OWASP не выданы за право или закон. Автозаполнение остаётся технической методикой, финансовый смысл определяет компания.

Строка PDF в карте URL, разложение замера и семь объектов пагинации — явные учебные примеры.
