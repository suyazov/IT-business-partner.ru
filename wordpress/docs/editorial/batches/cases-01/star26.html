Кратко о проекте

Для коттеджного посёлка «Звёздный» я разработал сайт на WordPress по макетам Figma. Покупателю нужно изучить участки, таунхаусы, дома и планировки, затем оставить обращение.

Одна из задач — интерактивная карта посёлка. Заказчик должен самостоятельно менять объекты и данные карты в административной части, а не обращаться за каждой правкой к разработчику.

Задача

Нужно было:

  • сверстать сайт по дизайну из Figma;
  • разработать WordPress-сайт с нуля без визуальных конструкторов;
  • создать удобную структуру управления контентом через ACF-поля;
  • реализовать интерактивную схему коттеджного посёлка;
  • дать заказчику возможность редактировать объекты и данные карты из админки;
  • разместить информацию о таунхаусах, участках, планировках и материалах строительства;
  • добавить разделы с ходом строительства и сданными проектами;
  • реализовать формы обратной связи;
  • подключить квиз для подбора таунхауса без ежемесячной абонентской платы;
  • выполнить техническую поисковую оптимизацию сайта;
  • адаптировать сайт под мобильные устройства.

Результат

Разработал и опубликовал сайт на star26.ru. На этапе передачи реализованы:

  • сайт, созданный с нуля по дизайну из Figma;
  • индивидуальную адаптивную вёрстку без Elementor;
  • административное управление контентом через ACF PRO;
  • интерактивную редактируемую карту посёлка;
  • каталог участков, таунхаусов и домов;
  • характеристики и планировки объектов;
  • формы обратной связи;
  • многошаговый квиз без ежемесячной абонентской платы;
  • технически подготовленную основу для поискового продвижения;
  • возможность самостоятельно обновлять ключевые данные сайта.
