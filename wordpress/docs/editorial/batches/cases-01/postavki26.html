Кратко о проекте

Для городского портала Postavki26 я разработал площадку, где поставщики Ставрополя размещают товары и услуги. Покупатели ищут предложения в общем каталоге и переходят на страницы компаний.

Поставщику нужен был собственный кабинет: добавлять предложения без доступа к административной части WordPress. Администратору — управление участниками, категориями и публикациями.

Задача

В состав задачи входили:

  • поставщик должен сам регистрироваться на сайте;
  • у поставщика должен быть личный кабинет;
  • поставщик должен добавлять товары и услуги без входа в административную часть WordPress;
  • товары должны попадать в общий каталог;
  • пользователи должны искать товары по категориям, названию и цене;
  • у каждого поставщика должна быть своя страница;
  • администратор должен управлять поставщиками, товарами, категориями и публикациями;
  • сайт должен быть понятным для предпринимателей, которые не являются техническими специалистами.

Результат

Разработана площадка с регистрацией и личными кабинетами поставщиков. Результат — функции размещения и поиска предложений, а не подтверждённое увеличение числа сделок между компаниями.

  • Поставщики самостоятельно размещают товары и услуги.
  • Предложения попадают в общий каталог с поиском по категориям, названию и цене.
  • У каждой компании есть собственная страница.
  • Администратор управляет поставщиками, товарами, категориями и публикациями.
