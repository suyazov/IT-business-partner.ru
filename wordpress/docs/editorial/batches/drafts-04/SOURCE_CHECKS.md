Mapped Markdown сопоставлен с полными прочитанными runtime-body. Предметные абзацы совпадают; отличающиеся формулировки ссылок рассмотрены отдельно. Для исходных editorial/articles прочитаны только назначенные секции `#id=52/62/72/82/92`, а не соседние клиентские данные. Пути исходников указаны в manifest.

Портфельная фактура взята из принятых публичных body: LibertyGas, Маткласс, Formula Lead, Битрикс24 для дверной компании, анонимная форма курс/мероприятие, HR-требования, дашборд найма и Design-Moskva. Новые тесты прямо описаны как план или учебный пример. Ни одна статья не получает клиентские показатели, неизвестный стек или функции соседнего проекта.
