Кратко о проекте

Для строительной компании ПроффСтрой я собрал лендинг по макету Figma. На нём представлены ремонт, строительство и реконструкция объектов в Кисловодске и окрестностях.

После вёрстки внёс комментарии заказчика: оформление первого экрана, логотип, тексты услуг и фотографии выполненных работ. Добавил галерею с просмотром фотографий и формы обращения.

Задача

Задача включала вёрстку, доработку контента и подготовку проекта к переносу:

Собрать страницу по макету и исправить первый экран.

Разместить нужный логотип, услуги и блок причин выбора компании.

Добавить галерею с просмотром изображений и формы обращения.

Подготовить архив проекта без служебных файлов для другого хостинга.

Результат

Подготовил лендинг с услугами, этапами работы, фотографиями объектов и формами. Проект собран для переноса на другой хостинг; состоявшийся перенос этим описанием не подтверждается.

Для обработчика форм нужны PHP и работающая функция mail(). Само наличие mail() не подтверждает доставку письма получателю — её проверяют отдельно после размещения.
