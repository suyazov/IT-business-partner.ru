Кратко о проекте

Для существующего сайта Asia Shadrin я сверстал и опубликовал страницу первой статьи блога по макету Figma. Нужно было сохранить стиль сайта и встроить новый шаблон в MODX.

Отдельного мобильного макета не было. Поэтому адаптацию под телефон делал на основе desktop-дизайна и уже используемых элементов сайта.

Задача

Нужно было:

  • сверстать страницу статьи по макету из Figma;
  • встроить её в существующий сайт на MODX;
  • использовать готовые блоки сайта там, где это возможно;
  • добавить 2 формы обратной связи по аналогии с другими страницами;
  • сохранить стилистику сайта Asia Shadrin;
  • адаптировать страницу под мобильные устройства без отдельного мобильного макета;
  • опубликовать результат на рабочем URL;
  • внести финальные правки после проверки заказчиком.

Результат

Опубликовал статью на рабочем адресе, встроил две формы обратной связи и внёс финальные правки после проверки заказчиком. Подготовленный шаблон можно использовать как основу следующих статей.

  • готовую страницу статьи на рабочем домене;
  • оформление в стилистике сайта;
  • встроенные формы обратной связи;
  • адаптивное отображение;
  • возможность использовать этот подход как основу для следующих статей блога.
