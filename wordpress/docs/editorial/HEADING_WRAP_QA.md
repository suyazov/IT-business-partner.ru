# Перенос длинных слов в заголовках

Во время редакционного preview на320px найдены 13 страниц с прежними длинными словами в H1/H2, выходившими из собственной строки. Добавлено только `overflow-wrap:anywhere` для H1 шапки и H2/H3 тела основного сайта. Размеры шрифта, тексты, блоки и URL не меняются. Правило ограничено `.brand-sy3`; версия темы повышена до1.4.8 для обновления asset cache при будущем выпуске.

23.10.2026 проверены все 13 воспроизводимых случаев: шесть страниц первых коммерческих/публичных пакетов, две из drafts-01 и пять из drafts-02. Точное добавленное CSS-правило подставлено в собственный изолированный локальный browser context: до него проблема воспроизводится, после — ни обрезанных заголовков, ни горизонтального выхода страницы. Preview CSS, тела WordPress и production не изменялись.

Evidence: private/editorial-refactor-20261023/heading-wrap-preview.json, включая hash файла CSS и результаты до/после каждой страницы. Это исправление переноса, не reader test и не проверка личного сайта. Само по себе source merge не разрешает production-деплой.
