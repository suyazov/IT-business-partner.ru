# Черновик: зачем я перестраиваю свои сайты

Статус: редакционный черновик. Публиковать только после фактического запуска и обновления формулировок по результату.

У меня было два сайта: один представлял услуги по Битрикс24, второй — меня как IT-бизнес-партнёра. Я решил связать их роли и собрать экспертные материалы в одном месте.

На sy3.ru подготовлены направления CRM, интеграций и автоматизации с ИИ, подробные кейсы и журнал. Личный сайт объясняет мой подход и ведёт к конкретным работам.

Для управления выбран WordPress. Главные страницы и материалы доступны в редакторе блоков. В кейсах отдельно указаны выполненные работы и ограничения проверки: техническое изменение не становится доказательством роста продаж само по себе.

После запуска будет полезно оценить, какие материалы приводят к предметным разговорам с клиентами. Пока результат этапа — подготовленная версия сайтов и контент.
