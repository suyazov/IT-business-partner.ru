# Проверяемые факты этапа

- Подготовлена собственная тема WordPress для двух ролей: коммерческий sy3.ru и личный it-business-partner.ru.
- Написаны три страницы услуг и десять новых разборов; подключены 25 существующих кейсов AFFiNE с Share, 23 готовые обложки и каталог по направлениям.
- Для переноса сохранены восемь прежних карточек портфолио и три публикации блога; неотобранный архив в локальном кандидате сохранён в черновиках.
- Основные тексты редактируются стандартными блоками WordPress, без внешнего page builder.
- Дизайн переработан по четырём указанным владельцем референсам: тёмный технологичный первый экран, локальный Manrope, собственная WebGL-графика, светлая версия личного сайта. Подробности в `docs/DESIGN.md`.
- Обращения — прямые ссылки на Telegram, почту и телефон; новая форма и аналитические трекеры не подключались.
- Проверка редактора главной: 112 блоков, ни одного невалидного блока.
- Production ещё не переключён. Новые обращения, рост трафика, экономия и продажи результатом этого этапа не подтверждены.

Источники прежних кейсов указаны в `content/cases.json`. Их результаты не перепроверялись на клиентских production-системах в этой задаче.
