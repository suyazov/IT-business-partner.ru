# Визуальные материалы

В этой версии созданы собственные SVG-схемы: путь обращения, CRM, интеграция, ИИ-пилот и графическая карточка автора. Это схемы, не скриншоты интерфейсов и не фотографии.

Если позже понадобятся растровые обложки через разрешённый браузерный ChatGPT-процесс:

> Редакционная иллюстрация для статьи об автоматизации бизнеса. Тёплый светлый фон, графитовые линии, сдержанный светло-зелёный акцент. Показать связь входящего обращения, CRM, задачи сотруднику и контроля результата. Без логотипов сторонних компаний, персональных данных, имитации реального CRM-скриншота, числовых результатов и текста. Формат 16:9.

Генерация не запускалась. Для реального портрета использовать предоставленную владельцем фотографию; не создавать вымышленное фото автора.
